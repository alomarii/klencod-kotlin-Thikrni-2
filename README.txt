تطبيق ذكرني - تذكير بالصلاة على النبي صلى الله عليه وسلم
برمجة وتطوير: محمد العمري - 730215825

طريقة التشغيل:
1) افتح المجلد Thikrni في Android Studio (إصدار Hedgehog أو أحدث، JDK 17).
2) انتظر مزامنة Gradle ثم اضغط Run أو Build > Build APK(s).
3) عند أول تشغيل اسمح بالإشعارات، ثم اضغط "السماح بالعمل في الخلفية" ليعمل التذكير عند الشحن وفتح القفل بشكل ثابت.

المميزات:
- التاريخ الهجري (أم القرى مع تعديل ±٣ أيام) والميلادي مع ساعة حية
- تذكير دوري تختار مدته (٥ د، ١٠ د، ١٥ د، ٣٠ د، ساعة، ساعتان، ٣ ساعات أو مدة مخصصة)
- تذكير عند توصيل الشاحن وعند فتح قفل الهاتف
- عدّاد للصلاة على النبي مع زر "صلّيت" داخل الإشعار
- خلفية متحركة ونجوم وتأثيرات ذهبية، وشعار "الاخوة"
- يعمل بعد إعادة تشغيل الهاتف
الحد الأدنى: Android 7.0 (API 24)

تحديث: التذكير صوتي فقط بتسجيل بشري (بدون صوت آلي وبدون إشعار تذكير).
- من داخل التطبيق اضغط "اختيار صوت الصلاة على النبي من هاتفك" واختر أي تسجيل صوتي بصوت قارئ فصيح (mp3/m4a/ogg/wav).
- أو ضع ملفًا باسم salawat.mp3 داخل app/src/main/res/raw/ قبل البناء ليكون الصوت الافتراضي.
